# Пипкаигры

> «Играл с пипкой — проиграл»

Браузерные игры для **TrackPoint** — красной пипки между клавишами G, H и B на ThinkPad.

AI written, slop alert issued;

[English version](README.md) · Сайт: GitHub Pages из корня репозитория, открыть `/`.

## Идея

Пипка отдаёт не координату, а **нажим**: внутри тензодатчик, и курсор едет тем быстрее,
чем сильнее давит палец. Это миниатюрная ручка управления, которая сама возвращается в
ноль, когда её отпускают. Игры сделаны под это: там, где обычная игра читает позицию
курсора, они читают силу. В браузере это Pointer Lock: относительные дельты
`movementX/Y`, делённые на время кадра, дают скорость курсора в px/s, пропорциональную
нажиму, а экспоненциальный фильтр превращает её в отклонение ручки от −1 до +1. Что
игра делает с этой силой — скорость, натяг, щелчок, направление в момент отпускания, —
открытый вопрос, который игры и исследуют.

Ползунок под каждой игрой задаёт нажим, который считается полным отклонением. У разных
ThinkPad'ов пипка разной жёсткости, так что значение своё на каждой машине и запоминается
в браузере. Системная скорость самой пипки — отдельно:

```sh
xinput list                                      # найти "TPPS/2 ... TrackPoint"
xinput set-prop <id> "libinput Accel Speed" 0.4
```

## Игры

| | |
|---|---|
| [**Пипка-Пилот**](plane/) | Ночной слалом, где самолёт ведут, а не двигают: между пальцем и траекторией два интегрирования. |
| [**Пипка-Трек**](race/) | Монца на пипке: отбойники, визг покрышек по углу увода задней оси и принципиально без заднего хода. |
| [**Пипка-Космонавт**](moon/) | Посадка на Луну, где половина хода пипки — зависание, а бак подобран так, чтобы его всегда чуть-чуть не хватало. |
| [**Пипка-Данмаку**](danmaku/) | Почти тохо: процедурные волны, и каждая девятая — Сырно, ⑨ как положено. |
| [**Пипка-Коровка**](ladybird/) | Для трёхлетки: проиграть нельзя, а ладошка по клавиатуре — это воздушный шарик. |
| [**Пипка-Буквы**](letters/) | Коровка учится читать: буквы по порядку, звуки сгенерированным голосом, статистика для родителя. |
| [**Пипка-Феерия**](feerie/) | Туннель, который снится сам себе: мандалы с прорезями, ноты-бусины, а проигрыш называется рассветом. |
| [**Пипка-Катапульта**](catapult/) | Орки в 3D: пипка крутит ворот, натяг — это дальность, а красные быстрее летают. |

## Документация

* **Хаб** (`index.html`) — сайт: таблица-оглавление со временем, токенами и моделью по
  каждой игре и вкладка на игру — что попросили, как заказ стал этой игрой и что пошло
  не так.
* **`<игра>/README.ru.md`** — подробности одной игры: управление, модели, цифры, проверки.
* **`<игра>/card.js`** — вкладка этой игры на хабе: заказ, история, метрики.
* **[AGENTS.md](AGENTS.md)** — правила для того, кто здесь что-то меняет, агента или
  человека: структура, что обязано быть в каждом документе, жёсткие правила игр.

Зависимостей и сборки нет: каждая игра — один HTML-файл, который открывается прямо с
диска.

```sh
setsid -f xdg-open index.html >/dev/null 2>&1   # или просто открыть в браузере
node physics-test.js                              # модели машины, лунного модуля и катапульты
```

`setsid -f` нужен, чтобы Ctrl-C в терминале не убил браузер (в zsh сработает и `&!`).
