# Пипкаигры

> «Играл с пипкой — проиграл»

Игры для **TrackPoint** — красной пипки между клавишами G, H и B на ThinkPad.

[English version](README.md) · Сайт: включить GitHub Pages на репозитории
(Settings → Pages → Deploy from branch, root) и открыть `/`.

Пипка отдаёт не координату, а **нажим**: внутри тензодатчик, и курсор едет тем быстрее,
чем сильнее давит палец. Это миниатюрная ручка управления, которая сама возвращается в
ноль, когда её отпускают. Обе игры сделаны под это: они читают силу там, где обычная
игра читает позицию курсора. Со стороны браузера — Pointer Lock: относительные дельты
`movementX/Y`, делённые на время кадра, дают скорость курсора в px/s, пропорциональную
нажиму; экспоненциальный фильтр (τ = 60–70 мс) превращает её в аналоговое отклонение
ручки от −1 до +1.

| Путь | Что это |
|---|---|
| `index.html` | Хаб сайта: обе игры и комментарий разработчика к каждой |
| `plane/index.html` | **Пипка-Пилот** — ночной слалом: крен, инерция, створы ворот |
| `race/index.html` | **Пипка-Трек** — кольцо в духе Монцы, отбойники, звук |
| `physics-test.js` | Прогон модели машины: `node physics-test.js` |

Зависимостей и сборки нет: три самодостаточных HTML-файла.

```sh
setsid -f xdg-open index.html >/dev/null 2>&1   # или просто открыть в браузере
node physics-test.js
```

`setsid -f` нужен, чтобы Ctrl-C в терминале не убил браузер (в zsh сработает и `&!`).

## Управление

Общее: поле захватывает курсор, `Esc` — пауза, стрелки — запасное управление, ползунок
снизу задаёт чувствительность пипки, кнопка `EN`/`RU` переключает язык (выбор общий для
всего сайта через `localStorage`).

**Пипка-Пилот** — влево/вправо крен, вперёд/назад газ.

**Пипка-Трек** — влево/вправо руль (ход зажимается на скорости), вперёд газ, назад
тормоз, `Пробел` ручник, `R` вернуться на трассу. Заднего хода нет: на двухосевом органе
управления «назад» уже занято тормозом, а отличить торможение от желания сдать назад
можно только по состоянию, которого палец не чувствует.

## Чувствительность

Ползунок задаёт порог нажима в px/s, при котором отклонение считается полным. У разных
ThinkPad'ов пипка разной жёсткости, так что на каждой машине значение своё; оно
запоминается в `localStorage` этого браузера. Машине обычно хочется порог повыше, чем
самолёту.

Системная скорость самой пипки крутится отдельно:

```sh
xinput list                                      # найти "TPPS/2 ... TrackPoint"
xinput list-props <id>
xinput set-prop <id> "libinput Accel Speed" 0.4
```

## Физика машины

Велосипедная модель в метрах и ньютонах, фиксированный шаг 1/120 с, так что поведение не
зависит от частоты кадров:

* боковая сила шины считается **в системе самого колеса**, поэтому всегда направлена
  против скольжения — хоть передом, хоть задом, хоть в развороте;
* сила линейна по углу увода и ограничена сцеплением `mu*Fz`;
* эллипс трения на каждой оси: продольная сила съедает боковой бюджет — отсюда срыв
  кормы от газа и потеря зацепа под торможением;
* перенос веса по продольному ускорению меняет нагрузку на осях;
* тормоз поделён между осями (5900/3400 Н), чтобы ни одна не вышла за свой бюджет;
* торможение двигателем на сброшенном газе; заднего хода нет;
* ход руля ограничен по сцеплению: при полном отклонении запрос примерно на треть выше
  предела шин — занос спровоцировать можно, а удержанный до упора руль юлу не крутит;
* трава — сцепление 0.55 против 1.30 на асфальте и шестикратное сопротивление качению;
  ручник режет сцепление задней оси до 28%;
* отбойники по краям: отскок ≈ 0.35, скрёб вдоль стены, гашение вращения, искры и удар
  в звуке.

Измерено `node physics-test.js`: разгон 0–100 за 6.4 с, максималка 146 км/ч, торможение
со 108 км/ч — 45 м при среднем 1.02 g, накат со 108 до 18 км/ч — 12.8 с, руль в упор на
72 км/ч даёт 1.22 g без разворота, занос гасится сам за 2.7 с.

## Трасса

В духе Монцы: главная прямая 212 м, Реттифило, Курва Гранде, Роджиа, два Лесмо, прямая
Серральо, связка Аскари и длинная Параболика — 14 поворотов, круг 869 м, ширина 12 м.

Центровая линия — не сплайн, а **полигон со скруглением углов дугами заданного
радиуса**: у каждого поворота радиус задан явно, петля замкнута по построению. Сплайн
через опорные точки пробовался и выброшен — его кривизна пикует ровно в опорных точках,
и получались радиусы 5–8 м при ширине трассы 10, то есть внутренняя кромка ленты
сворачивалась сама в себя.

Проверено численно до использования: минимальный радиус 104 px (13 м, около 47 км/ч в
Аскари 3), нигде несоседние участки ленты не ближе 238 px при требуемых 164, габарит
укладывается в мир 3200×2100 px. Старт-финиш ставится на середину главной прямой,
поребрики раскладываются по знаку кривизны.

## Звук

Всё синтезируется в WebAudio, сэмплов нет: двигатель — пила плюс квадрат через ФНЧ,
частота и срез по псевдооборотам; визг покрышек — белый шум через полосовой фильтр с
громкостью по **углу увода задней оси**, то есть включается ровно тогда, когда уходит
зад; шорох травы — тот же шум через ФНЧ, по скорости вне трассы; удар об отбойник —
шумовой всплеск плюс металлический призвук, по нормальной составляющей скорости удара.
Контекст создаётся по кнопке старта (раньше браузер его не пустит) и усыпляется на паузе.
